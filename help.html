1快速开始（30 秒上手）

第一次打开会出现身份选择页，选一个即可开始。

打开链接首次进入会显示「我是老师 / 我是家长」选择页
点「🎒 我是老师 · 带一个班」填班级名、粘贴学生名单（可以不填，之后随时导入）
点「开启班级模式」系统自动给每个学生随机分配一只幻兽，班内不重复
开始加减分学生攒积分 → 幻兽升级进化（幼年期→成长期→成年期→究极体）
建议马上做两件事：① 右上角「老师」→ 设置 PIN，防止学生误入老师面板；② 「数据备份」里导出一次 JSON 存档。

2建班与导入名单

名单支持从 Excel / 花名册直接复制粘贴。

粘贴格式：一行一个学生，姓名后空格写分组名（可选）张小明 第一组　李小红 第一组　王小刚 第二组
自动处理：序号（1. 2. 、）自动去掉；重名学生自动跳过；新分组自动创建
追加导入：之后在「老师 → 名单管理」随时补人；「替换导入」会清空当前班重新开始
每个学生随机分到一只幻兽，全站共 50 种（5 只经典 + 45 只班级专属），同班不重复；超过 50 人才允许重复。
删除学生不会立刻消失在名单导入里——请用「名单管理」逐个删除或整班替换，删除前会二次确认。

操作怎么用适合场景
单人加分点任意学生卡片 → 选 +1/+2/+4/+6 或 -1/-2/-3，也可点「± 自定」输入任意分值 → 点理由胶囊（积极回答、作业优秀…）或自己输入 → 确认课上随堂表扬
批量加减分全班页「☑️ 批量加分」→ 点选多个学生（支持全选、按组选）→ 选统一分值 → 一次提交整组作业完成、集体扣分
自定义分值任何加减分面板点「± 自定」→ 输入如 8 或 -3 → 确定；最近用过的自定义分值会自动变成快捷按钮测验加 8 分、特殊奖惩
改默认按钮右上「老师」→「快捷分值」（或 班级设置 → 自定义加减分按钮）→ 填常用分值（逗号隔开，扣分填正数会自动变 −）→ 保存，实时预览让按钮贴合自己的课堂习惯
全班加分「⚡ 全班加分」→ 一键给班里每个人加同样的分全班晨读达标、流动红旗
随机点名「🎲 随机点名」→ 先选范围（全班或某一组）→ 名字快速滚动、逐渐减速，定格的「就是你！」 → 可顺手 +1/+2 分或「再来一次」抽过的人本轮不再出现，一轮抽完自动开新一轮；右下角可静音
加分同时幻兽获得 EXP 并升级进化，学生看到的是「自己养宠物」——正向激励就这么来的。

🎡幸运抽奖

功能怎么用说明
幸运大转盘商店页顶部横幅 / 个人页「🎡 幸运抽奖」进入 → 按显示价格抽一次奖池就是老师上架的奖品，票价按奖品定价自动计算（约 30% 空奖、长期返还 65%）
实物礼品抽中后自动进「待确认」，老师点 ✓ 发放不再二次扣积分，属于免费领奖
经验道具 🧪抽中后立即生效：直接给当前幻兽加经验，可能当场升级不需要老师确认，不进待确认；弹窗会显示 +多少经验、升了几级
动态票价老师改奖品定价，抽奖价格自动跟着变；也可直接指定票价「管理奖池」里填票价：0 = 按奖池自动算，正整数 = 用你定的价（如全班统一 10 分一次）
概率公开抽奖页「奖池与概率」表格，学生看得见越贵的奖品中奖概率越低（按定价反比分配），改票价后返还率会实时重算；奖池最多放 7 件奖品
转盘只是动画展示，落点按真实概率计算；扇区大小不代表概率大小，以概率表为准。

4光荣榜与小组 PK

三个周期：今日 / 本周 / 总榜，按天记录得分，不怕历史记录被清理
前三名领奖台：金银铜牌 + 大头像，4 名以后排序列表
小组 PK：按人均分画条形图（人数不等的小组也公平），点榜单右上角「小组」切换查看
投屏小技巧：电脑 / 平板横屏打开会自动切换成大屏横屏模式——领奖台和榜单左右并排、学生墙多列铺满、底部导航变成悬浮胶囊，用浏览器全屏（F11）就是一块即时的班级大屏。

5多班管理与跨班对比

切换班级：全班页点顶部「班级名 ⌄」→ 弹出班级列表 → 点一下即切换
新建班级：班级列表底部「＋ 新建班级」；每个班的名单、积分、幻兽完全独立
删除班级：「老师 → 班级设置 → 删除当前班级」（红色按钮，二次确认）
跨班对比：有 2 个班以上时，全班页出现「📊 跨班对比」→ 看各班人均积分排名 + 年级 TOP10 混排榜，点学生可直接跨班加分
任务规则和礼品清单是所有班共用的，改一次全班生效；学生名单和数据按班隔离。

6礼品商店（积分兑换）

维护奖品：商店页右上角「管理礼品 ›」（仅老师可见）→ 添加 / 编辑 / 上下架 / 删除 / 恢复默认 / 改抽奖票价
添加奖品：先选类型——🎁 实物礼品 或 🧪 经验道具；再选图标（30 个 emoji）+ 名称 + 积分 + 说明
经验道具：填「增加经验」（如 30），并设定一个兑换价。学生兑换或抽中后立刻加给幻兽，不需要老师确认；定价同时决定抽奖中奖概率
上下架：奖品临时发完就「下架」，学生端立即隐藏，随时再上架
兑换流程：学生点实物礼品 → 提交兑换请求 → 老师在「兑换记录 / 待确认」里批准或拒绝 → 批准后扣积分；经验道具点一下直接扣分并加经验
兑换记录：老师面板「🎁 兑换记录」→ 分「待兑换」和「已兑换」两个页签，全班同学的兑换申请和历史一目了然，可直接 ✓ / ✕ 处理
学生的兑换申请必须由老师在「待确认」里处理才生效；拒绝不扣分。

7老师面板（右上角「老师」）

入口功能
⚡ 批量加减分 / 🎲 随机点名（可选组） / 👥 名单管理 / 🏆 光荣榜 / 📊 跨班 / 🎁 兑换记录高频工具直达
待确认处理学生的兑换申请
任务管理 / 奖励管理配置日常任务和商店奖品；每个任务的分值、每个奖品的定价都能随时改（列表里点 ✏️）；分值填负数（如 -2）就是扣分项；面板顶部新版本默认任务就是课堂加减分清单（作业优秀 +2、交作业 +1、会背课文 +2、考试良好 +2、考试优秀 +4、满分 +6、考试进步 +2、不交作业 -2、不打卡 -1、上课说话 -3），支持增删和任意自定义
班级设置改班名、分组管理、学期重置（只清积分保留幻兽 / 全新开始）、关闭班级回到家庭模式
设置 PIN进老师面板要输 4 位 PIN，防学生误触
数据备份导出 / 导入 JSON 存档恢复；换设备用 📤 发到手机 或 📥 扫码接收，见下方
数据会自动同步到你自己的云端私有仓库（见第 ⑩ 章），本机也留有一份。仍建议每学期点一次「导出 JSON」存档，多一层保险。

📱手机扫码迁移（电脑 ↔ 手机）

电脑上建好的班，想放到手机上看；或者把手机里的数据搬回电脑 —— 扫一扫，不用传文件。

两台设备同时打开本应用，扫码即可迁移全部数据（班级、名单、积分、宠物、礼品）。
① 数据在哪台，就在哪台点「发到手机」老师 → 数据备份 → 📤 发到手机：屏幕出现二维码。数据多时会分成几张，点「下一张」，也可开「自动翻页」
② 另一台打开同一个网址 → 老师 → 数据备份 → 📥 扫码接收手机会请求摄像头权限，点「允许」，把镜头对准屏幕上的码，约 1 秒识别
③ 逐张扫完自动合并进度条显示「已收到 2 / 3 张」，全部收齐后自动弹出预览（班级名、人数）
④ 点「确认导入」覆盖本机数据并刷新。导入前系统会把本机这份自动存进「恢复历史版本」，导错了还能找回
扫不动怎么办？① 点二维码可全屏放大，离远一点更好对焦；② 手机端还有「粘贴导入」兜底；③ 数据特别大（超过 20 张码）就改用「导出 JSON」传文件。
导入会覆盖接收设备上的现有数据。两台都开着云同步（默认开启）时，日常根本不用扫码 —— 打开网页就自动同步；扫码只用于其中一台没网、或云端还没同步过的场合。

9家庭模式（家长用）

适合：家里 1-3 个孩子，从幻兽蛋开始养成
任务：家长配置「叠被子 +2」「练琴 20 分钟 +3」等，孩子自己勾选提交，家长确认到账
奖励：孩子用积分兑换奖励（看动画、小零食…），家长确认后兑现
切换：老师随时可在「班级设置 → 关闭班级模式」回到家庭版，两边数据互不影响

10云同步（多台电脑互通）· v3.18 零配置

几台电脑（各班教室机 + 办公室电脑）共用同一份成绩，不用填任何东西——打开就自动同步。

场景会发生什么
打开应用自动拉取云端最新成绩，直接就是最新的
加减分约 20 秒后自动上传，不弹窗、不打断课堂
页面一直开着每 60 秒自动检查一次云端，有更新就自动刷新（老师 45 秒内操作过则顺延，不打断加分）
切回窗口 / 重开立刻拉取最新
断网照常加减分，数据存本机；联网后自动补传，不丢分
应用关掉 / 电脑关机不联网也不同步；下次打开时自动补上。建议设开机自启，开机即最新

多位老师一起用

每位老师的数据各自独立存放，互不覆盖、互不可见：

情况怎么做
第一位老师（已部署）无需任何操作：更新后自动认作「老师1」，继续用原来的数据
新老师第一次打开弹一次「这台电脑是谁在用？」→ 点已有老师，或输入称呼点「新建」（数据独立）。选完不再问
想改显示名☁️ 云同步面板 → 当前老师旁「改名」（每台各改一次）
一台电脑多人共用☁️ 云同步面板 → 高级设置 → 切换老师身份

首次对接与手动操作

建立云端数据：只在数据最全的那台 → 老师 → 数据备份 → ☁️ 云同步 → 点「↑ 立即上传」
其他电脑：打开页面自动拉取；也可手动点「↓ 立即下载」
顺序：先上传再下载。几台同时各点「上传」，最后上传的那台会覆盖其他台的成绩

数据保险：恢复历史版本

每次云端数据要覆盖本机前，都会自动留一份本地快照（保留最近 5 份）。删错学生、积分被改乱时：☁️ 云同步 → 🕘 恢复历史版本 → 选一个时间点 → 恢复（恢复前当前数据也会再留一份）。

合并规则：每个班级独立比较时间戳，后改的班覆盖先改的班；同一班在两台电脑同时改，以时间新的为准。所以尽量一个班同一时间只在一台电脑上操作。

同步令牌已内置在应用里，权限仅限「读写班级数据」这一个私有仓库，改不了你 GitHub 上的其他任何东西。想用自己的仓库，可在 ☁️ 云同步 → 高级设置里覆盖。

11常见问题

问题解答
打开还是旧版？把页面完全关闭后重新打开一次即可自动更新；首页底部/首次页会显示版本号（v3.4+）
两台设备数据互通吗？互通，且不用配置：打开各自的应用就自动同步（见第 ⑩ 章）。只在旧版 v3.17 之前、或想手动搬一次时，才用「手机扫码迁移」
关掉网页还会同步吗？不会（浏览器不允许后台运行）。打开应用时自动补上；建议设开机自启，开机即最新。页面一直开着时每 60 秒自动检查更新
几位老师能一起用吗？能，各自数据独立存放。新电脑第一次打开会问「这台电脑是谁在用」，选一次即可（见第 ⑩ 章）
学生能看到别的学生吗？同一设备打开就是老师视角；建议班里的设备由老师保管，或设置 PIN
幻兽会重复吗？同班内 50 种幻兽不重复分配；跨班可能重复；超过 50 人的班允许重复
电脑/大屏能用吗？能。横屏（或电脑浏览器）打开会自动切换横屏大屏模式：光荣榜左右分栏、学生墙多列、弹窗居中，适合教室一体机投屏
断网能用吗？能。已加载过的页面支持离线使用（PWA）；联网打开会自动更新到最新版
能装到手机桌面吗？能。浏览器菜单 →「添加到主屏幕」，之后像 App 一样全屏打开
误扣分了怎么撤？再给该学生加回相应分数即可；「记录」页有完整流水可查
