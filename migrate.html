旧数据还能找回来吗

浏览器把数据按网址分开存放，所以新网址里看不到旧网址的数据。分两种情况：

如果旧网页还能打开（有些设备留着离线缓存）：先断开网络，打开旧链接 → 老师 → 数据备份 → 导出，存成 JSON 文件；再联网打开新网址 → 数据备份 → 导入。
如果旧链接白屏、报错：说明那台设备没留缓存，数据无法迁移，只能在新版里重新建班。以后建议开着云同步（默认已开），换设备就不用再搬数据。
